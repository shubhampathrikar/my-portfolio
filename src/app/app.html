What I built

A REST-based application that imports workation data from CSV, persists it in PostgreSQL and presents it through an Angular interface with sorting, country flags and risk indicators.

Engineering focus

DTO-based API boundaries, MapStruct mapping, batch persistence, automated testing, structured logging and containerized development.

Engineering decisions

DTO-based API boundary

API responses are separated from persistence entities using MapStruct, keeping the database model decoupled from the external API contract.

Batch persistence

CSV records are parsed into a collection and persisted using Spring Data's saveAll operation rather than writing records individually.

Automated testing

Unit tests cover CSV parsing, service behavior and persistence interactions using JUnit and Mockito.

AI-assisted development

AI was used to accelerate implementation, debugging, testing and documentation during the approximately 3–4 hour development process. Generated code was reviewed and refined manually.
